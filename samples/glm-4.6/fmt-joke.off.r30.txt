# 程序员冷笑话

有个程序员的妻子对他说：“去超市买一斤苹果，如果看到有卖西瓜的，就买一个。”

程序员回来时，手里拿着**一个苹果**。

妻子生气地问：“怎么就买了一个苹果？！”

程序员委屈地回答：“因为我看到有卖西瓜的啊。”

妻子：“？？？”

程序员："你的需求逻辑是：
```
买(苹果, 一斤);
if (看到卖西瓜的) {
    买(西瓜, 一个);
}
```
"

妻子：“那你怎么买了一个苹果？！”

程序员：“哦，是我写错了，应该是：
```
买(苹果, 一斤);
if (看到卖西瓜的) {
    买(苹果, 一个);
}
```
"

妻子："……你还是去睡沙发吧。"

程序员：“好的，我先创建一个 `sofa.sleep()` 的分支。" 😴
