The watermelon one is really a classic Chinese programmer joke and fits "冷笑话" perfectly - it's about literal logical interpretation of instructions:

老婆给程序员老公打电话："下班路上买十个包子，如果看到卖西瓜的，就买一个。"

老婆问："怎么就买了一个包子？"
程序员："因为我看到卖西瓜的了。"

This works because the programmer interpreted it as:
buyBuns(10);
if (seeWatermelonSeller) { buy = 1; } // buy 1 of... what? The condition modifies the count

Actually the joke interpretation is:
买十个包子 (buy 10 buns)
如果看到卖西瓜的，买一个 (if you see watermelon sellers, buy one)

The programmer interprets "买一个" as overriding/being the condition branch - so if condition is true, buy 1 (bun), else buy 10 buns. Like:

if (看到卖西瓜的) { 买一个包子 } else { 买十个包子 }

Or alternatively, some interpret it as the count changes to 1. Either way, the humor comes from the programmer's overly literal/logical parsing of ambiguous natural language.
