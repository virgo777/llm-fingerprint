# 程序员冷笑话

一个程序员的妻子对他说：

**“去超市买一斤包子，如果看到卖西瓜的，就买一个。”**

结果程序员买回来**一个包子**。

妻子怒问：“怎么就买一个包子？！”

程序员委屈地说：

> "因为我看到卖西瓜的了啊。
> 
> ```
> if (看到卖西瓜的) {
>     买包子数量 = 1;
> }
> ```
> 
> 逻辑没毛病啊！"

---

😂 这个笑话的精髓在于：程序员把“如果看到卖西瓜的，就买一个（西瓜）”理解成了“买一个**包子**”——条件语句的优先级完全跑偏了。

还有一个更短的：

**问：程序员最讨厌哪个节日？**

**答：万圣节（Halloween）。**

**因为 Oct 31 == Dec 25**
（八进制的31等于十进制的25，一个经典的进制梗）
